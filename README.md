# Calendar Bot

Личное расписание в Telegram: события со временем начала, дела на день,
напоминания за 15, 5 и 1 минуту и утренняя сводка. У каждого пользователя
свой часовой пояс и настройки. Доступ ограничен числовыми Telegram ID.

Бот использует Python 3.14+, aiogram, SQLite и OpenAI Responses API.
Он разбирает свободный текст, ищет время публичных событий и автоматически
сохраняет новые записи с напоминаниями. Изменения и удаление подтверждаются
кнопками; выполнение дела отмечается одним нажатием. Просмотр расписания
и доставка уже запланированных напоминаний работают без AI.

## Быстрый локальный запуск

Потребуются Linux, Python 3.14, токен отдельного тестового бота от
[BotFather](https://t.me/BotFather) и OpenAI API-ключ с доступом к выбранной модели.
Один Telegram-токен нельзя одновременно использовать в двух polling-процессах.
Команды выполняются из корня репозитория.

### Подготовка окружения

```sh
python3.14 -m venv .venv
.venv/bin/python -m pip install --require-hashes -r requirements.txt
cp -n .env.example .env
```

### Настройка

Заполните в `.env` значения `BOT_TOKEN`, `OPENAI_API_KEY` и `ALLOWED_USER_IDS`
(числовые Telegram ID через запятую). Если свой ID пока неизвестен, оставьте
список пустым: после запуска бот покажет ID отправителя в личном чате, не давая
доступ к календарю. Затем внесите ID и перезапустите процесс.

[Пример конфигурации](.env.example) задаёт модель и путь локальной БД
`data/calendar.sqlite3`. Требования к модели и полный список параметров описаны
в [контракте конфигурации](DEPLOYMENT.md#конфигурация).
Переменные окружения имеют приоритет над `.env`; другой файл можно выбрать
параметром `--env-file`.

В примере **включена запись общения с моделью** через
`OPENAI_TRACE_DIR=data/model-traces`. Файлы содержат личный текст сообщений.
Для отключения задайте пустое `OPENAI_TRACE_DIR=` и перезапустите процесс.
Подробности — в [диагностике разбора](docs/development.md#диагностика-разбора).

### Инициализация и запуск

Для новой локальной установки создайте пустую БД, проверьте конфигурацию
и запустите бот.

```sh
.venv/bin/python -m calendar_bot migrate
.venv/bin/python -m calendar_bot check
.venv/bin/python -m calendar_bot run
```

`check` проверяет конфигурацию, БД и Telegram через `getMe`; OpenAI при этом
не вызывается. Для автономной проверки БД и конфигурации есть `check --offline`.
Если БД уже содержит данные, используйте
[порядок миграций](DEPLOYMENT.md#изменения-данных). Обычный запуск миграции не выполняет.

В личном чате отправьте `/start`, выберите часовой пояс и добавьте, например,
«завтра 16:00 встреча» или «завтра купить продукты». Дальнейшие сценарии описаны
в [руководстве пользователя](docs/usage.md). Для штатной остановки нажмите Ctrl+C.
